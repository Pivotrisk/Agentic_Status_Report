# Example Input Case

This folder contains the sample input document set that corresponds to the reference output in [example output](../format/example_output.md).

Use this folder as the preserved example case while the main `input/` folder is reused for new cases.

## Included Files

- `claim_form.pdf`
- `deputation.pdf`
- `police_report.pdf`
- `policy.PDF`
- `quotation.pdf`
- `written_agreement.pdf`

## Notes

- These files are the example input set for the TR International / Sitapaila case.
- You can now replace the files in `input/` with a new case without losing this reference example.
- If you later want prompt guidance based on example input/output pairs, this folder and [the reference output](../format/example_output.md) can be used together.
