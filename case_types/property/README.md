# Property Case Type

This folder contains the current property insurance workflow.

Included now:

- `format/property_format.md` as the approved property status survey report format
- `format/format.md` retained as a compatibility copy of the approved property format
- `format/template.docx` as the property Word template for exact-format report generation
- `format/example_output.md` as a sample output reference
- `prompt_manual.md` as the property manual workflow prompt
- `fields.json` as the current property extraction schema
- `examples/` copied from `example_input/`
- `previous_inputs/` and `previous_outputs/` copied from the old root-level history folders
- `archives/` for completed property cases
- `scripts/` helper scripts for property workflow reference

Daily active work belongs in `Working_3/current/input/` and `Working_3/current/output/`.

Use this as the stable property baseline before introducing marine, motor, engineering CAR, agriculture, and miscellaneous formats.
